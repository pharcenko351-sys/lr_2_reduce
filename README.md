# ЛР 2, варіант 13 — `std::reduce` і політики виконання

Програма міряє, скільки часу займає `std::reduce` на масивах різного розміру:
без політики, з `seq` / `unseq` / `par` / `par_unseq`, а також у власній
багатопотоковій версії з K потоками.

## Компіляція

Проєкт збирається на Windows у середовищі [MSYS2](https://www.msys2.org/).

1. Встановіть MSYS2 і відкрийте з меню «Пуск» термінал **MSYS2 MINGW64**.
2. Поставте компілятор, `make` і бібліотеку TBB:

   ```bash
   pacman -S make mingw-w64-x86_64-gcc mingw-w64-x86_64-tbb
   ```

Що з цього потрібно програмі:

| інструмент | роль |
|---|---|
| `g++` (GCC, MinGW-w64) | компілює код за стандартом C++20 |
| oneTBB (`-ltbb12`) | реальне паралельне виконання для `std::execution::par` і `par_unseq`: стандартна бібліотека GCC віддає йому роботу з потоками |

## Як зібрати і запустити

```bash
make bench
```

Буде зібрано два виконувані файли: `reduce_O0.exe` (оптимізацію вимкнено) і
`reduce_O3.exe` (максимальна оптимізація). Обидва запускаються, а їхній вивід
записується у `results/run_O0.txt` і `results/run_O3.txt`.

Лише зібрати — `make`, видалити бінарники — `make clean`.

## Вхідні файли

Лежать у `data/` під іменами `numbers_<N>.txt`, N = 10 000, 100 000,
1 000 000, 10 000 000.

Формат:

```
<N>
<x1> <x2> ... <xN>
```

У першому рядку кількість чисел, у другому самі числа (цілі з
[1, 100000]) через пробіл. Генеруються `std::mt19937` +
`std::uniform_int_distribution`.

Коли файлів немає, програма створює їх із фіксованим seed = 2718. Коли вони
вже є, просто читає їх, тож обидві збірки працюють з однаковими даними.
Ключ `--regen` перезаписує всі файли з випадковим seed:

```bash
./reduce_O3.exe --regen
```

## Як влаштовано вимірювання

- операції: `add` (звичайна сума) і `mul_mod` (добуток за модулем
  1 000 000 007). Обидві асоціативні й комутативні, тому `std::reduce`
  може безпечно переставляти елементи;
- спочатку один прогрівочний запуск, потім медіана з 15 запусків;
- рахується лише сам `reduce` на масиві в пам'яті, час читання файлу виводиться
  окремим рядком;
- `equal = ok` означає, що відповідь збіглася з `std::reduce` без політики.
